v1.2.0
-Uses Obfuscar 2.2.50.
-Obfuscated builds now need the .NET 10 runtime (x64) or later, including for .NET Framework projects.
-Supports .NET (SDK-style) projects, including WPF single-file publish. Version 1.x did not obfuscate these.
-Obfuscation now runs from _Obfuscar\Obfuscar.targets. Open Obfuscar Settings and save once to upgrade a project set up with version 1.x.
-WPF projects keep property names by default.
-Supports Visual Studio 2026.
